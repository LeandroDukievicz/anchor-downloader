01 O painel

02 O que ele faz

volume

Sabe o tamanho antes de começar

Uma primeira passagem percorre só os metadados, sem reter as mensagens, e confirma o total. O progresso passa a ter uma referência real em vez de crescer às cegas.

retomada

Continua de onde parou

Arquivos .part são retomados depois de queda de rede, reinício ou fechamento. Referências de mídia expiradas são renovadas sozinhas, sem perder o parcial já baixado.

paralelo

Uma conexão para dez janelas

Dez ou mais janelas compartilham uma única conexão com o Telegram, coordenadas por um serviço local. O limite global evita abrir fluxos que a conta não aguentaria.

limites

Aguenta o flood wait

Espera automática para os limites do Telegram, inclusive o FloodPremiumWait de contas não Premium — e a espera é combinada entre todas as janelas, não repetida por cada uma.

saída

Organiza sozinho

Fotos, Vídeos, Músicas, Áudios, Documentos, Legendas, GIFs, Stickers e Outros. Cada destino ganha um manifesto de verificação e um relatório final em texto.

memória

Estável por dias

Fila limitada para canais grandes, liberação periódica de buffers no serviço compartilhado e descriptografia nativa por cryptg, para o Python não virar o gargalo.

privacidade Você usa o seu próprio API ID e API Hash de my.telegram.org. A autenticação fica no seu computador em StringSession, com permissão restrita ao seu usuário. Não existe servidor intermediário — o programa fala direto com o Telegram.

03 Instalar

recomendado

pipx

Ambiente isolado, comando disponível de qualquer pasta, sem mexer no Python do sistema.

sudo apt install -y pipx pipx install anchor-downloader pipx ensurepath

Atualizar: pipx upgrade anchor-downloader

loja

snap

Atualização automática. Para baixar num HD secundário ou externo, libere o acesso uma vez.

sudo snap install anchor-downloader sudo snap connect anchor-downloader:removable-media

O destino padrão ~/Downloads/Telegram funciona sem liberar nada.

código-fonte

git

Para desenvolver ou rodar uma versão ainda não publicada.

git clone https://github.com/LeandroDukievicz/anchor-downloader.git cd anchor-downloader ./install.sh

Requer python3-venv.

comandos
  • anchor-downloaderinicia normalmente
  • --demopainel com dados simulados
  • --offlineabre sem conectar ao Telegram
  • --doctorverifica a instalação sem conectar
  • --versionmostra a versão instalada
